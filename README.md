# Deep Core

Co-op dig-site incremental: start with a rusty shovel, end with a bucket-wheel.

**[Download DeepCore.exe](https://github.com/ArthurPluto/deep-core-releases/releases/download/v0.1.0/DeepCore.exe)** (Windows 10/11, 64-bit). Put it in a folder of its own (not
Program Files) and run it. It checks for updates on every start and installs them by itself.

Windows SmartScreen may say "Windows protected your PC" the first time: the exe is not
code-signed yet. Click "More info", then "Run anyway".

Release notes: [all releases](https://github.com/ArthurPluto/deep-core-releases/releases).
